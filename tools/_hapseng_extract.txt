======================================================================
Session 1 ΓÇö Prompt Engineering
Contoso Consolidated Berhad   |   Microsoft 365 Copilot Premium
Session 1 ΓÇö Prompt Engineering with M365 Copilot
Audience: Contoso Consolidated managers across Finance, Ops, Sales, Marketing, After Sales
Duration: 90 min (Demo time: ~25 min, the rest = framework explanation + Q&A + audience prompt practice)
License: M365 Copilot Premium
Demo Flow (Keep it tight ΓÇö 25 minutes total)
Opener (5 min) ΓÇö The "Bad vs Good" Prompt
Open Microsoft 365 Copilot Chat (Work mode). Show side-by-side what a one-line prompt produces vs a structured one.
Bad prompt (live):
Write me an email to the plantation managers
(Generic, no audience, no purpose, no tone.)
Good prompt (live) ΓÇö using the G-C-S-E framework:
GOAL: Draft an email to the 7 Plantation Estate Managers reminding them
that Q2 CapEx submissions are due by 25 June.

CONTEXT: I am the Group Treasury Manager at Contoso Consolidated Berhad.
The estates have missed the last two deadlines. Tone should be firm but
collegial ΓÇö I still need their cooperation for Q3.

SOURCE: Use the attached CapEx submission template and the email thread
from last quarter where I followed up on missed deadlines (paste below).

EXPECTATION: Subject line + 4 short bullet points + sign-off
"Regards, Treasury". Under 150 words. No jargon.
≡ƒÆí  Teaching point: G-C-S-E = Goal ┬╖ Context ┬╖ Source ┬╖ Expectation.
≡ƒÆí  - Goal ΓÇö what do I want Copilot to do?
≡ƒÆí  - Context ΓÇö who am I, who is the audience, what's the situation?
≡ƒÆí  - Source ΓÇö what data, file, or reference should it use?
≡ƒÆí  - Expectation ΓÇö format, length, tone, structure of the output.
>
≡ƒÆí  You don't need all four every time, but the more of these you give, the better the output.
Demo 1 (8 min) ΓÇö Prompt a messy inbox into action
File to use: Demo Files\01_Messy_Email_Thread.txt (paste into Copilot Chat)
Prompt:
Below is a 3-day email thread between Contoso Consolidated Treasury and the
Automotive division about a delayed FX hedging request.

1. Summarise the thread in <100 words.
2. List every decision that was made (with who decided it).
3. List every open question still unresolved, tagged with whose ball it is.
4. Draft a 4-line reply from me (Treasury) that closes the open items.

Tone: professional, no jargon.
What to highlight while it runs:
Numbered output ΓåÆ forces structure
Asking for "who owns it" ΓåÆ drives accountability
"Draft a reply" combines analysis + action in one prompt
Demo 2 (6 min) ΓÇö Same data, different lens (Context matters)
Same Source, same Expectation ΓÇö but change the Context and watch the answer move. Use Demo Files\02_Q1_Division_Snapshot.txt.
Prompt A ΓÇö Finance lens:
GOAL: Tell me the 3 numbers I should worry about most.
CONTEXT: I am a Finance Business Partner at Contoso Consolidated.
SOURCE: The Q1 divisional snapshot below.
EXPECTATION: 3 bullets, each with a one-line "why this matters".
Prompt B ΓÇö Operations lens (run immediately after, same chat):
Now keep the same SOURCE but change CONTEXT: I am an Operations Manager
preparing for next week's MANCOM. GOAL: surface the 3 biggest operational
risks I should flag. EXPECTATION: 3 bullets, each tagged with the
division it relates to.
≡ƒÆí  Teaching point: Same data, different Context = different insights. Copilot follows the lens you give it.
Demo 3 (6 min) ΓÇö The "improve my prompt" cheat code
Show the Researcher agent with a deliberately weak prompt, then use the Refine prompt suggestion that Copilot offers.
Weak prompt (type this):
Research palm oil prices
When Copilot shows the auto-refine suggestion, click it. Show the rewritten prompt ΓÇö point out that Copilot itself just modelled G-C-S-E (it added Goal clarity, Context, a Source hint, and Expectation).
≡ƒÆí  Teaching point: When stuck, ask Copilot to improve your prompt before you run it.
≡ƒÆí  Try: "Improve this prompt so it gives me a board-ready answer: [your prompt]"
Sample Prompt Library ΓÇö by Function
Hand this out / paste into chat as a starting kit.
≡ƒÆí  Each prompt below maps cleanly to G-C-S-E. Read them and spot the four parts.
Finance & Treasury (42% of audience)

      raise with the divisional FC.
CONTEXT: I am a Finance Manager at Contoso Consolidated reviewing a Q1
         variance report ahead of my 1:1 tomorrow.

EXPECTATION: Three sections ΓÇö (1) Key risks (2) Management response
             (3) My recommended next action. Keep all numbers exactly
             as in source. Under 1 page.

CONTEXT: I am a Plant Operations Manager doing my morning walkaround.

             (with duration) | Escalations needed today.

         customer requested a quote 5 days ago and went silent.
SOURCE: Original quote and email thread below.
EXPECTATION: Warm, low-pressure tone. Give them an easy 'yes'.
             End with ONE clear CTA. Under 120 words.
Marketing
GOAL: Brainstorm 5 campaign angles for our new sustainable
      building-materials line.

EXPECTATION: Ticket with ΓÇö customer summary | root cause hypothesis |
             recommended response | escalate-to-GM Y/N with reason.
Audience Practice (15 min)
Ask attendees to:
Pick one task they did today.
Write the prompt using G-C-S-E (Goal ┬╖ Context ┬╖ Source ┬╖ Expectation).
Run it. Share what worked / didn't.
Watch-outs
Don't paste anything from a confidential customer or HR system into a free Copilot Chat. Always use Work mode (green shield = grounded in tenant data, not used for training).
Output is a draft, not a decision. Always verify numbers before forwarding.
If response is too generic ΓåÆ strengthen Context. If too long or off-format ΓåÆ tighten Expectation. If facts feel made up ΓåÆ give it a Source.
